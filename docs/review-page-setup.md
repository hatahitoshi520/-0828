# 口コミ投稿ページ（review.html）導入ガイド

来店客向けのアンケートページです。星評価と選択式の質問から**口コミの下書きを自動作成**し、
ボタン1つで「文章をコピー → Googleの口コミ投稿画面を開く」まで行います。
お客様は貼り付けて投稿するだけなので、口コミ投稿の手間が大幅に減ります。

## 仕組み

| 評価 | 表示されるもの |
|---|---|
| ★4〜5 | 良かった点の選択 → 下書き作成 → **Googleで投稿ボタン** |
| ★1〜3 | 気になった点の選択 → 下書き作成 → **Googleで投稿ボタン** ＋「お店に直接伝える」フォーム |

## なぜ「高評価だけGoogleへ自動投稿」にしていないのか

1. **Googleのポリシー違反になるため**
   評価によってGoogleへの投稿導線を出し分ける行為（レビューゲーティング）は、
   Googleのクチコミポリシーで禁止されています。違反すると口コミの削除や
   ビジネスプロフィールの表示制限を受けるおそれがあります。
   また、景品表示法のステルスマーケティング規制にも抵触するおそれがあります。
2. **技術的に不可能なため**
   Google Business Profile API は「口コミへの返信」はできますが、
   お客様の代わりに口コミを投稿する機能はありません。代理投稿は偽の口コミにあたります。

そのため本ページは **全員にGoogle投稿の導線を出し**、投稿の手間を最小化する設計にしています。
低評価のお客様には、それに**加えて**お店へ直接届く窓口を用意し、不満をその場で受け止めて改善につなげます。

## 導入手順

1. このリポジトリを GitHub Pages 等で公開する（`review.html` が配信されればOK）
2. Google の「Place ID Finder」で自店舗の **プレイスID**（`ChIJ...`）を調べる
3. `https://<公開URL>/review.html?setup` を開き、店舗名・プレイスID・フィードバック送信先を入力
4. 「お客様用URLとQRコードを作成」を押し、QRコードを保存してレジ横・テーブル・レシートに掲示

## URLパラメータ

| パラメータ | 内容 | 必須 |
|---|---|---|
| `pid` | Google プレイスID | ○ |
| `shop` | 店舗名（画面に表示） | |
| `mail` | 直接フィードバックの送信先メール（メールアプリが起動） | |
| `hook` | 直接フィードバックの送信先URL（JSONをPOST。Google Apps Script等） | |
| `chips` | 「良かった点」の選択肢（カンマ区切り） | |

`hook` と `mail` の両方を指定した場合は `hook` を優先します。

### hook の受け口例（Google Apps Script → スプレッドシートに記録）

```js
function doPost(e) {
  const d = JSON.parse(e.postData.contents);
  SpreadsheetApp.getActiveSheet().appendRow(
    [d.sentAt, d.shop, d.rating, (d.items || []).join('、'), d.comment, d.contact]);
  return ContentService.createTextOutput('ok');
}
```

「デプロイ → 新しいデプロイ → ウェブアプリ（アクセス：全員）」で発行したURLを `hook` に設定します。

## 運用上の注意

- 口コミの見返りに割引や特典を渡すことはGoogleのポリシーで禁止されています。
- 下書きはあくまで補助です。お客様が自由に編集・削除できる状態を保ってください。
