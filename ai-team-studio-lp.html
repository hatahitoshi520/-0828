ROLES

高レベルはOpus、中レベルはSonnet。
判断の監査はFable、細かい分岐は軽量モデル。

それぞれのモデルを得意な仕事に置くことで、速さ・コスト・品質のバランスを取ります。

Opus / high

司令塔

全体計画とタスク分解、成果の統合、最終的な出荷判断を担当します。

Sonnet / medium

実働部隊

explorer・worker・researcher の3ロール。既存のサブエージェントを活かし、足りない役だけ新規作成します。

Fable

監査役

普段は待機。セッション全体を見たうえで、決まった3つのタイミングだけ口を出します。

軽量モデル

高速ルーティング

大きなモデルで考えるまでもない定型の判断を、速く安いモデルに任せます。

ADVISOR

Sonnetが働き、Fableが疑い、Opusが決める。

監査役が相談を受けるタイミングを CLAUDE.md にルールとして書き込みます。

PROCESS

勝手に書き換えない、5つのステップ

お客様の環境を壊さないことを最優先にしています。

01

診断

~/.claude/agents、.claude/agents、~/.claude/settings.json を読み取り専用で確認します。

02

棚卸し

既存のサブエージェントを explorer / worker / researcher に当てはめます。別のモデルに固定済みのものは変更せず、一覧にしてお渡しします。

03

阻害要因のチェック

advisor や effort 設定を無効化・上書きしうる環境変数や設定を洗い出し、報告だけ行います。

04

diff の提示

settings.json、エージェント定義、CLAUDE.md への変更をすべて diff 形式でご提示します。

05

「go」で適用

ご承認をいただいてから適用し、動作確認と引き継ぎ資料の作成まで行います。

--- a/.claude/agents/worker.md
+++ b/.claude/agents/worker.md
 ---
 name: worker
 description: 編集とテストを担当する実働エージェント
-model: inherit
+model: sonnet
 ---

FAQ

よくある質問

Anthropic社の公式サービスですか？

いいえ。当サービスは Anthropic社とは関係のない、独立した構築代行・研修サービスです。

advisor 機能が自分の環境で使えるか分かりません。

使える機能はプランや Claude Code のバージョンによって変わります。無料診断で実際に確認し、使えない場合は「監査役のサブエージェント」など、使える仕組みで同じ役割を作ります。

ソースコードや秘密情報を渡す必要はありますか？

ありません。作業はお客様の環境で、画面共有をしながら行います。ご希望があれば秘密保持契約（NDA）を結びます。

すでに作ったサブエージェントは消されますか？

消しません。既存のものを活かし、足りない役割だけを新しく作ります。別のモデルに固定されているエージェントは変更せず、一覧にしてお伝えします。

AIの利用料はいくらかかりますか？

使い方によって変わります。定型の作業を軽いモデルに任せるので、大きなモデル1つで全部こなす場合より抑えやすい構成です。目安は診断のときにお伝えします。
